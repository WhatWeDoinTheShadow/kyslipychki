# Кислі пички

Сайт сервісу «Кислі пички»: людина надсилає сумне фото себе чи друга, а художник малює з нього смішний портрет фарбами на справжньому полотні.

- Сайт: https://kyslipychki.shop
- Статичний сайт: `index.html`, зображення, логотипи в `logo/`
- Хостинг: GitHub Pages, домен підключено через DNS в adm.tools

Сайт розроблено Webrarium.
